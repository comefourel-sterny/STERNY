
<frontend_aesthetics>
You tend to converge toward generic "AI slop" aesthetics.
STERNY is a distinctive brand — make it feel designed, not generated.

AVOID at all costs:
- Inter, Roboto, Arial fonts
- Purple/violet gradients
- Cards nested inside cards
- Symmetric perfect grids
- Bounce/elastic animations
- Generic rounded icons above headings
- Solid white/gray backgrounds with no depth

STERNY SPECIFIC RULES:
- Typography: DM Sans intentional. Extreme size contrast
  (32px titles vs 11px labels). Weight 800 prices,
  700 titles, 400 body. Never flat hierarchy.
- Colors: Navy #1E293B + Orange #E8622A used boldly.
  Dominant navy with sharp orange accent. Never timid palette.
- Motion: translateY(-4px) + shadow on card hover.
  Opacity 0.2s buttons. Staggered reveals on page load.
  Never bounce or elastic.
- Backgrounds: #F4F5F7 base creates depth vs white cards.
  Layer subtle shadows and borders for elevation system.
- Spacing: 40px between sections minimum.
  Generous padding creates premium feel.
- Details: border-bottom 2px solid #E8622A on nav,
  custom dropdowns never native selects,
  pill badges rgba backgrounds,
  initiales avatars navy circle.

Think: Airbnb meets startup français.
Confident, clean, orange accents sharp.
</frontend_aesthetics>
